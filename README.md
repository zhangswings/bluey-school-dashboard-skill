# Bluey School Dashboard Skill

一个用于生成儿童学习仪表盘的 Codex Skill：把作息时间、课程表和每日提醒整理成清晰、可打印、适配 H5 / APP WebView 的单页网页。

## 能做什么

- 生成布鲁伊风格的蓝色、橙色、天空和奶油色视觉主题。
- 显示本地日期、中文星期和实时数字时钟。
- 显示可配置地点的当前天气和明日预报。
- 支持开学初作息、正常季节作息和完整课程表切换。
- 根据星期与当前时间显示今日课程和学习进度。
- 适配 360 / 390 / 430 / 768 / 1280 像素宽度。
- 支持键盘操作、触控按钮、安全区和 A4 横向打印。

## 使用方式

将 Skill 放入 Codex 的 skills 目录，或直接把 `SKILL.md` 作为任务规范使用。用户需要提供自己的课程表、作息表和（如需天气）天气位置配置；Skill 不内置任何固定地理位置、坐标或个人信息。

## 网页示例

示例位于 [`examples/bluey-school-dashboard`](examples/bluey-school-dashboard/)，是一个可直接用静态服务器打开的完整 HTML / CSS / JavaScript 页面。示例中的天气区域使用通用文案，便于复制后再配置。
